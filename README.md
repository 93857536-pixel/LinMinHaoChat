# LinMinHao Chat · iOS

端到端加密(E2EE)聊天 App —— iOS 原生版(SwiftUI + CryptoKit + Keychain)。

> 本仓库**不包含源代码**,只提供可直接安装使用的**未签名 IPA** 安装包。
> 安装需借助第三方签名工具(全能签 / ESign / SideStore 等),见下方说明。

## 功能

- 🔒 **端到端加密**:消息在发送前就在本机用 AES-256-GCM 加密,服务器只存密文;私钥仅存本机 Keychain,即使服务器被入侵也读不到聊天内容
- 💬 **临时聊天**:生成带验证码的链接发给对方,会话销毁后永久清除,无需注册
- 👤 **账号聊天**:手机/邮箱验证码登录注册(无密码),支持多设备、消息历史
- ⚡ **本机号码一键登录**:接入运营商号码认证,免收验证码(需 SIM 卡 + 蜂窝网络)
- 🕶️ **隐私模式**:消息气泡打码、无水印、截图检测提醒

## 安装方法(未签名 IPA)

未签名 IPA 不能直接安装,需要借助第三方签名/侧载工具:

1. 下载 `LinMinHaoChat-unsigned-v1.0.ipa`
2. 任选一种方式签名安装:
   - **全能签 App**(App Store 搜索"全能签"):选择"签名安装",读取本地 IPA,选"免费个人签"(7 天有效,到期重装即可);企业签可长期有效
   - **ESign / SideStore / AltStore** 等类似工具:导入 IPA → 用你的 Apple ID 免费签名安装
   - **电脑端工具**(如 AltStore):连接 iPhone 后直接安装 IPA
3. 安装后:设置 → 通用 → VPN 与设备管理 → 信任"林XX"(你的 Apple ID 用户名)
4. 打开 App,按提示验证即可

> 免费个人签名 7 天过期,重新签名一遍即可,账号数据保存在服务端,不受影响。

## 服务端

- App 自动连接官方服务 `https://chat.linminhao.top`,无需任何配置
- 官方 Web 版(电脑浏览器可用):`https://chat.linminhao.top`
- 账号:手机/邮箱验证码登录,**无密码**,首次使用自动创建账号

## 加密原理(简版)

| 层级 | 机制 |
| --- | --- |
| 消息 | HKDF-SHA256 派生密钥 + AES-256-GCM,AAD 绑定房间/序号/时间戳 |
| 身份 | Ed25519 签名密钥 + ECDH P-256 密钥对,私钥仅存本机 Keychain |
| 会话 | 端到端会话密钥经对方公钥包装(ECDH)传输,服务器全程看不到明文 |
