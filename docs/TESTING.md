## 浏览器端 E2EE 功能(需人工终验项)

- 临时聊天:创建 → 复制链接 → 隐身窗口打开 → 双方互发 → 解密显示
- 临时聊天刷新:页面刷新后界面清空、密钥销毁(fragment 清除)
- 临时聊天退出:本地清除,服务器归档保留
- 账号聊天:注册/登录 → 创建设置 → 双方互发 → 已读/在线状态 → 附件收发
- 多设备:导出密钥包 → 新浏览器导入 → 同一身份恢复会话
- 验证码:手机(需阿里云 SMS 开通后)、邮箱(需 DirectMail 开通后)
